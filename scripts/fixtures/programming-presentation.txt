Questions to Answer

1. How can Programming ensure sufficient
autonomy within LEED? (i.e. prevent bullying)
This is the role of the Chair and Vice Chair of Programming.
These positions meet regularly with the advisor to voice concerns and plans for
future programming efforts. As students and senior members of the Class
Programming Committee, they can “sanity check” LEED’s decisions so that
LEED does not make illogical choices again.
The increased responsibility of these roles, along with the advent of
whole-committee meetings, has pretty much eliminated information silos.

2. What distinguishes Class Programming from
the HOP and SGA Programming?
The way I see it:
- Class Programming: class-specific traditions and events (ex. formals) focused on class/school spirit and partnerships with various departments (ex. Athletics, STFE). Opportunity to create new big traditions.
- The HOP: numerous small fun events and huge flagship traditions. Limited opportunity to create new flagship traditions.
- SGA Programming: tablings and event sponsorships that promote student advocacy, meet the needs of the student body, and inform legislation

Examples of Class Programming events totally
separate from the HOP and SGA
- Battle of the Classes
- Family Weekend Talent Show (STFE partnership)
- Hoopy Holidays, Football Home Opener, and Lacrosse halftime events (Athletics partnership)
- Freshman Formal and Winter Wind-Down (FYE partnership)
- Sophomore Garden Party
- Junior Charity Gala (HopThon partnership)
- Senior Week

4. Should Class Programming become separate
from SGA? If so, how and when?
That is the million dollar question. :)

LEED’s Proposal
- “SGA would retain a designated programming leadership position, with the current Chair of Programming transitioning into a Recruitment and Retention Chair. This position would still be considered a member of the SGA Executive Branch, but would no longer be responsible for the day-to-day operations or oversight of class programming.
- “Following its transition out of SGA, Class Programming would operate as an independent student leadership initiative within LEED. The new organization would oversee individual class programming committees, Battle of the Classes, and other campus-wide school spirit and engagement initiatives.”

LEED’s Proposal
- Would have a new name like Spirit and Traditions Board (STB) or o Class Programming and Traditions (CPT).
- Org chart:
    - Elections for Chair, VC, and class committees (Chair, Treasurer, Media Director)
    - Appointed members with fewer responsibilities
    - Subcommittees for Athletics, Spirit, Media, etc.

My thoughts
- I definitely think the Class Programming Committees should become independent from SGA and focus more on school spirit.
    - We already have separate finances and org charts, Programming has no voting rights, SGA events perceived as “lame” (sorry)
    - Eliminate need to change SGA constitution for Programming stuff
    - Change should happen before next election cycle
- Class Programming may need an instagram name change because right now the class pages are “jhusgaXX”

My thoughts cont.
- HOWEVER, I do think SGA still needs some kind of Chair of Programming, who oversees the vision for events and actively helps with tablings.
    - I also think the Chair of Programming should be encouraged to think bigger (ex. the Major Fair)
- But this is all a lot of work for one position, as echoed by my predecessors. (Shoutout to Tim and Tyler)
- Recruitment and Retention Chair could be a new position that runs retreats and helps onboard new members, or folded into SGA Chair of Programming responsibilities.
- ALSO: this is not the end of the conversation. This is just the start.
